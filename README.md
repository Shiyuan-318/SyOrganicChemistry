# Sy Organic Chemistry

有机化学分子构建与展示工具

## 功能

- Canvas 2D 渲染分子骨架模型，支持平移缩放
- **3D 预览**：球棍模型 / 空间填充模型，支持旋转、缩放（Ctrl+/- 快捷键）
- 三种视图模式：2D 编辑 / 分屏 / 3D 预览
- 118个元素 + 21种官能团，点击或拖拽放置
- 智能自动成键（价键规则 + 键型推断）
- 化学键点击切换单/双/三键
- 分子式、结构简式、中文名称实时计算
- 加聚/燃烧/加成/消去/取代/水解等化学操作
- 右下角删除区域，拖拽原子即可删除
- 响应式适配平板和手机

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 打包桌面应用

```bash
npm run electron:build
```

## 版本历史

### v1.1.0
- 新增 3D 预览功能（球棍模型 + 空间填充模型）
