# Sy Organic Chemistry

有机化学分子构建与展示工具 / Organic Chemistry Molecule Builder & Viewer

## 功能

- Canvas 2D 渲染分子骨架模型，支持平移缩放
- **3D 预览**：球棍模型 / 空间填充模型，支持旋转、缩放（Ctrl+/- 快捷键）
- **3D 键角显示**：球棍模型下显示键角数值，杂化方式标注（sp/sp²/sp³）
- 三种视图模式：2D 编辑 / 分屏 / 3D 预览
- 118个元素 + 21种官能团，点击或拖拽放置
- **完整周期表视图**：标准 18 列周期表布局，一键切换
- **18种常见分子预设**：一键加载甲烷、乙醇、苯等
- 智能自动成键（价键规则 + 键型推断）
- 化学键点击切换单/双/三键，**楔形键/虚线键**表示立体化学
- 分子式、结构简式、中文名称、**分子量**、**IUPAC 命名**实时计算
- **SMILES 导入/导出**：支持从 SMILES 字符串生成分子
- **手性中心识别**与标记
- **同分异构体提示**
- **形式电荷计算**与标注
- **氧化态标注**
- **路易斯结构**：显示孤对电子
- **环检测**与高亮
- **共振结构**生成与切换
- **IR 光谱预测**：特征峰波数、强度、归属
- **NMR 光谱预测**：¹H 和 ¹³C 化学位移
- **pKa 预估**：酸碱性判断
- 加聚/燃烧/加成/消去/取代/水解等化学操作（带粒子动画效果）
- **撤销/重做**（Ctrl+Z / Ctrl+Y）
- **自动布局**：一键整理分子结构
- **缩放适配**：一键适配视图
- **复制/粘贴**原子组（Ctrl+C / Ctrl+V）
- **多分子标签页**：同时编辑多个分子，自由切换
- **保存/加载**：分子数据持久化到本地
- **导出 PNG/SVG**：一键导出分子图片
- **键盘快捷键**：Ctrl+Z/Y/S/E/C/V、Delete、Esc 等
- **触摸手势优化**：双指缩放、长按删除
- **暗/亮主题切换**
- **中/英文切换**
- 右下角删除区域，拖拽原子即可删除
- 右键上下文菜单
- 响应式适配平板和手机

## 开发
